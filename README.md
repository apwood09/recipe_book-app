# Recipe Book App

Recipie app where users choose a category from a dropdown menu and inputs recipe name, ingredients and steps to save recipe under choosen category. 
<br>

# Software Used
* Code Editor (e.g VS code)
* Html 
* Javascript 
* Css
<br>

# How To Use 

1. Fork/Clone Respiratory 
    * fork: 
        * click dropdown next to fork 
        * clck create new fork 
        * enter desired name for fork 

    * clone: 
        * click dropdown arrow next to code on the green button 
        * copy http 
        * open personal terminal & enter : git clone "HTTP ADDRESS HERE"
        * press enter 
    
2. Open In Code Editor
    * go into respiratory file: cd "RESPIRATORY NAME HERE"
    * open respiratory in code editor: code . 
    * locate index.html and right click: choose open in live server

3. Save Recipe 
    * top middle click save recipe
    * choose category 
    * input recipe name, ingredients & steps
    * click save button bottom center 

4. View Saved Recipe 
    * top middle click saved recipe
    * click on the category choosen for saved recipe 
<br>

REAPEAT steps 3-4 to save multiple recipes
