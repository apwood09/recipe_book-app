# Recipe Book App

Recipie app where users choose a category from a dropdown menu and inputs recipe name, ingredients and steps to save recipe under choosen category. 
<br>

# Software Used
* Code Editor (e.g VS code)
* Html 
* Javascript 
* Css
<br>

# How To Use 

1. Fork/Clone Respiratory 
    * fork: 
    a. click dropdown next to fork 
    b. clck create new fork 
    c. enter desired name for fork 

    * clone: 
    a. click dropdown arrow next to code on the green button 
    b. copy http 
    c. open personal terminal & enter : git clone "HTTP ADDRESS HERE"
    d. press enter 
    
2. Open In Code Editor
    a. go into respiratory file: cd "RESPIRATORY NAME HERE"
    b. open respiratory in code editor: code . 
    c. locate index.html and right click: choose open in live server

3. Save Recipe 
    a. top middle click save recipe
    b. choose category 
    c. input recipe name, ingredients & steps
    d. click save button bottom center 

4. View Saved Recipe 
    a. top middle click saved recipe
    b. click on the category choosen for saved recipe 
<br>

REAPEAT steps 3-4 to save multiple catgories
